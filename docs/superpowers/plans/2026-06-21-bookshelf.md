# Bookshelf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a trilingual "Bookshelf" section that renders a skeuomorphic wooden bookshelf of book spines; hovering a spine lifts it and floats its cover, and clicking opens that book's review page.

**Architecture:** Reuse the blog's existing patterns: a Jekyll `_books` collection mirrors `_articles` (per-language files linked by `ref`); per-language index pages are generated by extending `_plugins/i18n_pages.rb` exactly like categories/tags; shelf markup lives in `_includes/bookshelf-content.html`; the detail page is `_layouts/book.html`; all skeuomorphic styling lives in `assets/css/main.css`; interaction is CSS `:hover`/`:focus` plus a tiny vanilla JS tap handler (no Alpine).

**Tech Stack:** Jekyll 4.3+, Ruby, Liquid, Tailwind CSS (precompiled), custom CSS in `main.css`.

## Global Constraints

- No Alpine.js or runtime CDN scripts — only the precompiled `/assets/css/tailwind.css` + custom `/assets/css/main.css`. (The existing test asserts no `cdn.tailwindcss.com` / `unpkg.com/alpinejs`.)
- Skeuomorphic shelf/spine/cover styling goes in `assets/css/main.css` (served directly, no build step), matching the existing `.nav-link` / dark-mode-override convention.
- **If any template uses a Tailwind utility class not already present in the committed `assets/css/tailwind.css`, regenerate it** with `npm run build:css` and commit the result — CI/deploy do NOT run the CSS build, they use the committed file.
- Languages are exactly `en`, `ko`, `ja`; default is `en`. Every book has all three language files linked by an identical `ref`.
- Covers live at `assets/books/<ref>/cover.<ext>` (never inside the `_books` collection dir).
- Status values are exactly `reading`, `finished`, `wishlist`; shelf order is reading → finished → wishlist.
- Commit messages: Conventional Commits (`feat:`, `test:`, `style:`, `docs:`). **No co-author / AI attribution.**
- Run the suite with: `bundle exec ruby -Itest test/site_build_test.rb`

- [ ] **Step 6: Create the helper includes**

`_includes/book-cover-url.html` (prints resolved cover URL or empty — no surrounding whitespace):

```liquid
{%- assign u = "" -%}
{%- if include.book.cover and include.book.cover != "" -%}
  {%- assign u = include.book.cover | relative_url -%}
{%- else -%}
  {%- assign dir = "/assets/books/" | append: include.book.ref | append: "/" -%}
  {%- assign f = site.static_files | where_exp: "x", "x.path contains dir" | first -%}
  {%- if f -%}{%- assign u = f.path | relative_url -%}{%- endif -%}
{%- endif -%}
{{- u -}}
```

`_includes/book-color.html` (prints spine color):

```liquid
{%- assign palette = "#16314f,#6e2710,#123f24,#3f1873,#6e1717,#2c3a4d,#0f3d3a,#6b4a0f" | split: "," -%}
{%- assign idx = include.book.ref | size | modulo: palette.size -%}
{%- if include.book.spine_color and include.book.spine_color != "" -%}{{- include.book.spine_color -}}{%- else -%}{{- palette[idx] -}}{%- endif -%}
```

`_includes/book-rating.html` (prints a star row; expects `rating` param):

```liquid
{%- assign rating = include.rating -%}
{%- assign full = rating | floor -%}
{%- assign frac = rating | minus: full -%}
{%- assign next = full | plus: 1 -%}
<span class="book-stars" aria-label="{{ rating }} / 5">{% for i in (1..5) %}{% if i <= full %}<span class="star star--full">★</span>{% elsif i == next and frac >= 0.5 %}<span class="star star--half">★</span>{% else %}<span class="star star--empty">★</span>{% endif %}{% endfor %}</span>
```
